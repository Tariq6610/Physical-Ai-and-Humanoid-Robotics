# Contributing to Physical AI and Humanoid Robotics Book Project

We welcome contributions to the Physical AI and Humanoid Robotics Book Project! This document outlines the guidelines for contributing to this educational resource.

## Code of Conduct

This project adheres to the Code of Conduct outlined in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to the project maintainers.

## How to Contribute

### Reporting Issues
- Use the GitHub issue tracker to report bugs or suggest enhancements
- Provide as much detail as possible to help us reproduce the issue
- Check existing issues before submitting a new one

### Content Contributions
- Fork the repository and create a feature branch for your changes
- Follow the established documentation format (Docusaurus-compatible Markdown)
- Ensure all code examples are tested and functional
- Include proper attribution for any external sources
- Submit a pull request with a clear description of your changes

### Code Contributions
- Write clear, well-documented code
- Follow the project's coding standards
- Include tests for new functionality
- Ensure all tests pass before submitting

### Review Process
- All contributions will undergo a review process
- Feedback will be provided to help improve the contribution
- Changes may be requested before approval

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Commit your changes (`git commit -m 'Add some amazing feature'`)
5. Push to the branch (`git push origin feature/amazing-feature`)
6. Open a pull request

## Style Guide

- Use clear, accessible language appropriate for the target audience
- Follow the established chapter structure and formatting
- Include code examples with proper syntax highlighting
- Link to glossary terms when used for the first time in a chapter
- Ensure all diagrams and visuals are clear and purposeful

## Questions?

If you have any questions about contributing, please open an issue for discussion.
