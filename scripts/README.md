# Scripts

This directory contains utility scripts for the Physical AI and Humanoid Robotics project.

## Available Scripts

### `validate_code_examples.py`
Validates Python code examples in the documentation for syntax errors.

```bash
python scripts/validate_code_examples.py
```

### `check_broken_links.py`
Checks for broken links in the documentation.

```bash
python scripts/check_broken_links.py
```

### `ingest.py`
Content ingestion script for the RAG system (in backend/).

## Usage

Run these scripts from the project root directory to help with quality assurance tasks.
